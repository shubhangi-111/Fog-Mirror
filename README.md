# Fog Mirror

A minimalist smart fog mirror prototype with a hidden information display.

## Features

- Fogged mirror effect
- Interactive fog-clearing transition
- Dynamic clock and date
- Weather and humidity display
- Responsive layout
- Pure HTML, CSS and JavaScript
